### Hydrology monitoring — JPVL / NHPC *(live, 24×7)*

A consultancy build for JPVL to support round-the-clock weather and hydrological monitoring for JP Hydro Vishnuprayag, including NHPC-related context. The system ingests field data from stations such as Mana, Vasudhara, Barrage, and Benakuli, normalizes AWS and EWS telemetry in MySQL, and gives operators SCADA-style views, trends, and exportable reports for day-to-day plant decisions.

I built 15-minute CSV pipelines from Barani and Geolux dataloggers into validated parsers and relational storage. There are REST APIs for live and historical reads, JWT-based authentication, and role-aware access. The operator interface includes real-time dashboards, risk and discharge visualization, and map layers for spatial awareness. I handled API proxy and deployment patterns so the Next.js frontend and Node services work cleanly together. I was the sole developer end-to-end; the system is deployed and runs continuously at the plant.

**Live site:** https://hydrologyjpvl.cird.co.in
